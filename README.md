# ScamScope: Cyber Fraud Analytics

## Project Overview
ScamScope is an Excel-based data analytics project designed to analyze cyber fraud complaint patterns, financial losses, and recovery amounts. The dashboard helps users explore scam categories, payment channels, monthly complaint trends, and unrecovered financial losses.

**Note:** This project uses fictional sample data for learning and portfolio demonstration. It does not represent official cybercrime statistics.

## Business Problem
Cyber fraud can result in significant financial losses. Analyzing complaint patterns and recovery outcomes can help identify common scam types, understand financial impact, and highlight areas that may require greater awareness and prevention efforts.

## Project Objectives
- Identify the most frequent scam types.
- Analyze total financial losses by scam type.
- Compare recovered and unrecovered amounts.
- Track monthly complaint trends.
- Explore complaints by payment channel and state.
- Calculate recovery rate and average loss per complaint.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas

- Dashboard visualization

## Key Performance Indicators (KPIs)
- Total Complaints
- Total Money Lost (INR)
